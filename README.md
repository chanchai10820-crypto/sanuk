# sanuk

**สนุกคิด วิทยาการคำนวณ ป.3** เป็นเว็บบทเรียนออนไลน์รายวิชาวิทยาศาสตร์และเทคโนโลยี (วิทยาการคำนวณ) ชั้นประถมศึกษาปีที่ 3 อิงมาตรฐาน ว 4.2 ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551 (ฉบับปรับปรุง พ.ศ. 2560)

## เนื้อหา

| หน่วย | เรื่อง | ตัวชี้วัด | ชั่วโมง |
|---|---|---|---|
| 1 | อัลกอริทึมกับการแก้ปัญหา | ว 4.2 ป.3/1 | 10 |
| 2 | เขียนโปรแกรมด้วย Scratch | ว 4.2 ป.3/2 | 12 |
| 3 | ค้นหาข้อมูลด้วยอินเทอร์เน็ต | ว 4.2 ป.3/3 | 6 |
| 4 | รวบรวม ประมวลผล และนำเสนอข้อมูล | ว 4.2 ป.3/4 | 6 |
| 5 | ใช้เทคโนโลยีอย่างปลอดภัย | ว 4.2 ป.3/5 | 6 |

แต่ละหน่วยมี

- **แบบทดสอบก่อนเรียน** 10 ข้อ ทำได้ครั้งเดียว และยังไม่แสดงเฉลย
- **บทเรียน** 3–4 บท แต่ละบทมีตัวอย่าง กิจกรรม "ลองคิด" และสรุปท้ายบท
- **แบบฝึกหัด** 6–7 ข้อ แบบเลือกตอบ ถูก/ผิด เรียงลำดับ จับคู่ และเขียนคำสั่งบนตาราง (พาแมวไปหาปลา มีคำสั่งทำซ้ำ)
- **แบบทดสอบหลังเรียน** ใช้ข้อสอบชุดเดียวกับก่อนเรียน แต่สลับข้อและตัวเลือก ทำซ้ำได้ ระบบเก็บคะแนนสูงสุด แสดงเฉลยพร้อมคำอธิบาย

หน้า **ผลการเรียน** แสดงคะแนนก่อนเรียน หลังเรียน พัฒนาการ และระดับผลการเรียน (ดีมาก ≥ 80%, ดี ≥ 70%, ผ่าน ≥ 60%) นักเรียนคัดลอกสรุปผลส่งให้ครูได้

## วิธีเปิดใช้งาน

เว็บนี้เป็นไฟล์ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งหรือ build เปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000 หรือจะนำไปวางบน GitHub Pages ก็ได้

ความก้าวหน้าของนักเรียนเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้เรียนเท่านั้น ไม่มีการส่งข้อมูลไปที่เซิร์ฟเวอร์

## โครงสร้างไฟล์

```
index.html       หน้าเว็บหลัก
css/style.css    รูปแบบการแสดงผล (รองรับโหมดมืดและจอมือถือ)
js/content.js    เนื้อหา บทเรียน ข้อสอบ และแบบฝึกหัดทั้งหมด
js/app.js        การทำงานของเว็บ: เส้นทาง แบบทดสอบ แบบฝึกหัด ผลการเรียน
```

แก้ไขหรือเพิ่มเนื้อหาได้ที่ `js/content.js` ไฟล์เดียว รูปแบบข้อมูลของแต่ละหน่วยอธิบายไว้ที่หัวไฟล์
