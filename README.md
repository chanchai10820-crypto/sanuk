# sanuk

**สนุกคิด ป.3** เป็นเว็บบทเรียนออนไลน์ชั้นประถมศึกษาปีที่ 3 มี 2 รายวิชา เลือกวิชาได้จากแถบด้านบนของหน้าแรก

- **วิทยาการคำนวณ** (วิทยาศาสตร์และเทคโนโลยี) มาตรฐาน ว 4.2 · 5 หน่วย 19 บท 8 เกม
- **การงานอาชีพ** มาตรฐาน ง 1.1 · 4 หน่วย 13 บท 3 เกม

ทั้งสองวิชาอิงหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551 (ฉบับปรับปรุง พ.ศ. 2560) และใช้โครงสร้างเดียวกัน: บทละ 1 ชั่วโมง 6 ขั้น แบบทดสอบก่อน/หลังเรียนทั้งระดับบทและหน่วย แบบฝึกหัด เกม และแผนการสอน 40 ชั่วโมง

## เนื้อหาวิทยาการคำนวณ

| หน่วย | เรื่อง | ตัวชี้วัด | ชั่วโมง |
|---|---|---|---|
| 1 | อัลกอริทึมกับการแก้ปัญหา | ว 4.2 ป.3/1 | 10 |
| 2 | เขียนโปรแกรมด้วย Scratch | ว 4.2 ป.3/2 | 12 |
| 3 | ค้นหาข้อมูลด้วยอินเทอร์เน็ต | ว 4.2 ป.3/3 | 6 |
| 4 | รวบรวม ประมวลผล และนำเสนอข้อมูล | ว 4.2 ป.3/4 | 6 |
| 5 | ใช้เทคโนโลยีอย่างปลอดภัย | ว 4.2 ป.3/5 | 6 |

แต่ละหน่วยมี

- **บทเรียน** 3–5 บท (รวม 19 บท) บทละ 1 ชั่วโมง แบ่ง 6 ขั้น: ทดสอบก่อนเรียน 5 นาที → คำถามนำ 5 นาที → เรียนเนื้อหา 20 นาที → กิจกรรม 20 นาที → สรุป 5 นาที → ทดสอบหลังเรียน 5 นาที
  ทุกบทมีแบบทดสอบประจำบท 5 ข้อ คำถามนำ 2 ข้อ และแผนการสอน 60 นาทีสำหรับครู (จุดประสงค์ สื่อ กิจกรรมแต่ละขั้น การวัดผล)
- เนื้อหาบทเรียน แต่ละบทมีภาพประกอบ ตัวอย่าง ตัวอย่างเพิ่มเติม เรื่องที่มักเข้าใจผิด กิจกรรม "ลองคิด" คำศัพท์น่ารู้ (ไทย–อังกฤษ) กิจกรรมฝึกปฏิบัติ เกร็ดความรู้ และสรุปท้ายบท
- **แบบทดสอบก่อนเรียนหน่วย** 10 ข้อ ทำได้ครั้งเดียว และยังไม่แสดงเฉลย
- **แบบฝึกหัด** 6–7 ข้อ แบบเลือกตอบ ถูก/ผิด เรียงลำดับ จับคู่ และเขียนคำสั่งบนตาราง (พาแมวไปหาปลา มีคำสั่งทำซ้ำ)
- **แบบทดสอบหลังเรียนหน่วย** ใช้ข้อสอบชุดเดียวกับก่อนเรียน แต่สลับข้อและตัวเลือก ทำซ้ำได้ ระบบเก็บคะแนนสูงสุด แสดงเฉลยพร้อมคำอธิบาย

## เลือกชื่อผู้เรียน

ก่อนเริ่มเรียน นักเรียนเลือกห้อง (ป.3/5–3/8) แล้วแตะชื่อของทุกคนที่นั่งคอมพิวเตอร์เครื่องเดียวกัน เลือกได้สูงสุด 6 คน
คะแนนแบบทดสอบ บทเรียนที่อ่าน แบบฝึกหัด และดาวจากเกม จะบันทึกให้ทุกคนในกลุ่ม
แบบทดสอบก่อนเรียนทำได้คนละครั้ง ถ้ามีเพื่อนใหม่เข้ากลุ่มที่ยังไม่เคยทำ กลุ่มจะทำได้อีกครั้งและบันทึกเฉพาะคนที่ยังไม่มีคะแนน

หน้า **ผลการเรียน** แสดงตารางคะแนนของนักเรียนทุกคนที่เคยเรียนบนเครื่องนั้น และปุ่มคัดลอกสรุปผลส่งครู

### อัปเดตรายชื่อนักเรียน

รายชื่ออยู่ใน `js/roster.js` สร้างจากไฟล์ Excel บัญชีรายชื่อด้วยคำสั่ง

```bash
python3 scripts/build_roster.py บัญชีรายชื่อ.xlsx 3/5 3/6 3/7 3/8
```

repo นี้เป็นสาธารณะ สคริปต์จึงเก็บเฉพาะห้อง เลขที่ คำนำหน้า และชื่อจริง ไม่เก็บนามสกุลและเลขประจำตัวนักเรียน ห้ามนำไฟล์ Excel ต้นฉบับมาไว้ใน repo

## ลานเกม

| เกม | หน่วย | ฝึกเรื่อง |
|---|---|---|
| แมวหาปลา (8 ด่าน) | 1 | เขียนอัลกอริทึมด้วยลูกศร การทำซ้ำ |
| ทายเลขในใจ (3 ระดับ) | 1 | แก้ปัญหาแบบแบ่งครึ่ง |

| นักล่าบั๊ก | 2 | ตรวจหาข้อผิดพลาดในโปรแกรม Scratch |
| คัดแยกเว็บไซต์ | 3 | เลือกแหล่งข้อมูลที่น่าเชื่อถือ |
| นักสำรวจข้อมูล | 4 | นับด้วยรอยขีด สร้างแผนภูมิแท่ง อ่านข้อมูล |
| ฮีโร่ปลอดภัยออนไลน์ | 5 | รับมือภัยออนไลน์ |

ทุกเกมให้ดาว 1–3 ดวง (ใช้คำสั่งน้อยหรือตอบถูกมาก ยิ่งได้ดาวมาก) ดาวที่สะสมแสดงในหน้าแรกและหน้าผลการเรียน

หน้า **ผลการเรียน** แสดงคะแนนก่อนเรียน หลังเรียน พัฒนาการ และระดับผลการเรียน (ดีมาก ≥ 80%, ดี ≥ 70%, ผ่าน ≥ 60%) นักเรียนคัดลอกสรุปผลส่งให้ครูได้

## วิธีเปิดใช้งาน

เว็บนี้เป็นไฟล์ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งหรือ build เปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000 หรือจะนำไปวางบน GitHub Pages ก็ได้

ความก้าวหน้าของนักเรียนเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้เรียนเท่านั้น ไม่มีการส่งข้อมูลไปที่เซิร์ฟเวอร์

## โครงสร้างไฟล์

```
index.html       หน้าเว็บหลัก
css/style.css    รูปแบบการแสดงผล (รองรับโหมดมืดและจอมือถือ)
js/kit.js        ตัวช่วยที่ใช้ร่วมกัน (บล็อก Scratch ตารางเดิน)
js/art.js        ภาพประกอบ SVG ทั้งหมด
js/content.js    เนื้อหาวิทยาการคำนวณ บทเรียน ข้อสอบ และแบบฝึกหัด
js/plans.js      แผนการสอนรายชั่วโมงของวิทยาการคำนวณ คำถามนำ และแบบทดสอบประจำบท
js/career.js     เนื้อหาการงานอาชีพทั้งหมด (รวมแผนการสอนรายชั่วโมง)
js/roster.js     รายชื่อนักเรียน (เลขที่และชื่อจริง)
scripts/         สคริปต์สร้างรายชื่อจากไฟล์ Excel
js/games.js      เกมทั้ง 11 เกม
js/app.js        การทำงานของเว็บ: เส้นทาง แบบทดสอบ แบบฝึกหัด เกม ผลการเรียน
```

แก้ไขหรือเพิ่มเนื้อหาได้ที่ `js/content.js` ไฟล์เดียว รูปแบบข้อมูลของแต่ละหน่วยอธิบายไว้ที่หัวไฟล์
